# TP2-FerramenetasProdutividade
 
Este trabalho irá basear-se na resolução de dois exercícios de uma das aulas de Programação II, com agregação a um repositório público do GitHub, para todas as ações realizadas: implementação de classes e métodos para demonstrar conceitos básicos de programação orientada a objetos.
Verificaremos uma integração de conhecimentos de duas unidades curriculares : **Ferramentas de Produtividade**, com a utilização do GitHub para controlo de versões, e **Programação II**, com resolução de exercícios, em Java, seguindo a tipologia POO. 


### Descrição do projeto

- **Exercício 1**: Cálculo de volume e área de um cilindro.
    - Contém a classe `Cilindro` e o ficheiro `Exercicio1.java` com o método `main`.
- **Exercício 2**: Manipulação de dados de uma pessoa.
    - Contém a classe `Pessoa` e o ficheiro `Exercicio2.java` com o método `main`.
 
- **Método `main`**: Demostra as funcionalidades existentes nas classes associadas a cada um dos exercícios.


### Estrutura do projeto

Desta forma, podemos estruturar este projeto da seguinte forma:
````
TP2-FerramentasProdutividade/
├── Exercicio1.java        # Método main do exercício 1
├── Cilindro.java          # Classe auxiliar usada no exercício 1
├── Exercicio2.java        # Método main do exercício 2
├── Pessoa.java            # Classe auxiliar usada no exercício 2
└── README.md              # Documento com instruções e informações do projeto
````
